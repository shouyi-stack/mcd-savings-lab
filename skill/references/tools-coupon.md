## 3. `campaign-calendar` — 当月营销活动日历

- **用途**：查看进行中 / 即将到来的营销活动（品鉴会、主题派对、联名周边等）。
- **参数**：`specifiedDate`（可选，`yyyy-MM-dd`）。传入则以该日为锚点返回前后各一个有活动的日子；不传默认返回当月全部活动。
- **返回格式**：**Markdown 文本**。
- **实测状态**：✅ 2026-10-10（不传参，返回当月活动列表）。

**文本结构**

```
### 当前时间：<日期时间>
### 活动列表：
#### <日期> 往期回顾 / 今日 / （未来日期无前缀）
- **活动标题**：…
  **活动内容介绍**：…（多行文案，含 emoji）
  **活动图片介绍**：<img src="…" …>
```

**注意点**

- 活动按日期分段，前缀有「往期回顾 / 今日」等；图片是内嵌 HTML `<img>`，非结构化 URL 字段。
- 返回为人类可读文案（含营销 emoji），**不适合直接机器解析**；需提取时用「活动标题」行做锚点。

## 4. `available-coupons` — 查询可领取券

- **用途**：查询用户当前可领取的「麦麦省」优惠券列表。
- **参数**：无。
- **返回格式**：**Markdown 文本**。
- **实测状态**：✅ 2026-10-10（返回 6 张可领券）。

**文本结构**

```
### 麦麦省优惠券列表：
- 优惠券标题：<名称>
  状态：可领取
  优惠券图片：<img src="…" …>
```

**注意点**

- **不返回券 ID、面额、门槛等结构化字段**，仅有标题 / 状态 / 图片 —— 需要券 ID 或面额时需另寻工具（详见下方「券 ID 从哪来」）。
- 同名券可能重复出现（不同活动来源）。

## 5. `query-my-coupons` — 查询我的券包

- **用途**：查看用户卡包中**已拥有**的券（**非门店可用校验**，门店可用请用 `query-store-coupons`）。
- **参数**：`page`（默认 1，最多 5）、`pageSize`（默认 200，最大 200）。
- **返回格式**：**Markdown 文本**。
- **实测状态**：✅ 2026-10-10（返回 2 张券）。

**文本结构**

```
# 您的优惠券列表
共 N 张可用优惠券 | 第 x/y 页 | 每页 200 条
## <券名>
- **优惠**: ¥xx.x (用券价格)
- **有效期**: yyyy-MM-dd HH:mm-yyyy-MM-dd HH:mm <时间段>
- **领取时间**: <相对时间，如「今日收到」>
- **标签**: <如「到店专用」>
<img src="…">
```

**注意点**

- ⚠️ 「优惠」给的是**用券后价格（元）**，**不是面额**。想算「省了多少」需要同一餐品的**原价**做差：`立省 = 原价 − 用券后价格`。
- 「有效期」含两个时间片段（日期区间 + 每日可用时段），解析时注意拆开；`ledger` 用 `expire_at` 存结束时间、`daily_window` 存时段。
- 分页：`page` 最大 5，单页最大 200 —— 券很多时需翻页。
- **渠道差异**：券可能带「到店专用」等标签，外卖 / 到店适用范围不同，比对前先确认标签。

## 券 ID 从哪来（重要）

叠券算价的**前提**是拿到 `couponId` + `couponCode`，但本组三个工具**都给不了**：

| 工具 | 给不给 `couponId` / `couponCode` |
|---|---|
| `available-coupons` | ❌ 只有标题 / 状态 / 图片 |
| `query-my-coupons` | ❌ 只有「用券后价格」 |
| **`query-store-coupons`**（见 `tools-ordering.md`） | ✅ **给 `couponId` + `couponCode` + 适用 `products[].productCode`** |

→ 结论：**要叠券，必须走到 `query-store-coupons`**，`available-coupons` / `query-my-coupons` 只能做「有哪些券」的播报。
